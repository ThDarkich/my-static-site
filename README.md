# Мой статический сайт

Современный статический сайт, развернутый на GitHub Pages с использованием CI/CD.

## 📁 Структура проекта
my-static-site/
├── .github/workflows/ # CI/CD конфигурации
├── css/ # Стили
├── js/ # JavaScript
├── images/ # Изображения
├── index.html # Главная страница
├── about.html # Страница "О нас"
└── _config.yml # Конфигурация GitHub Pages

## 🌐 Деплой
Сайт автоматически деплоится при пуше в ветку `main`.

Production URL: https://thdarkich.github.io/my-static-site/
